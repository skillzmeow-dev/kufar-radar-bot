# 🚀 Kufar Monitor Bot (Telegram)

Быстрый и надежный Telegram-бот для мониторинга новых объявлений на **Куфаре (kufar.by)**.
Оповещает пользователя о появлении новых лотов (iPhone, аренда квартир, авто, видеокарты) за **10–15 секунд** после публикации — задолго до того, как их увидят обычные покупатели.

---

## 📁 Структура проекта

```text
kufar_monitor_bot/
├── config.py         # Настройки, регионы, категории, готовые пресеты
├── kufar_client.py   # Клиент к официальному API Kufar (быстрый JSON, фото, цены)
├── database.py       # База данных SQLite (пользователи, задачи, дедупликация)
├── keyboards.py      # Клавиатуры и кнопки управления
├── handlers.py       # Обработчики команд, FSM мастер добавления поиска
├── watcher.py        # Фоновый сервис непрерывного мониторинга
├── bot.py            # Точка входа для запуска бота
├── test_parser.py    # Скрипт проверки парсера в терминале без токена
├── requirements.txt  # Список библиотек (aiogram, aiohttp, aiosqlite)
├── .env.example      # Пример файла переменных окружения
└── .env              # Файл конфигурации с вашим токеном
```

## ⚡ Быстрый старт (За 2 минуты)

### Шаг 1: Проверка работы парсера
Вы можете прямо сейчас запустить тест и увидеть актуальные объявления с Куфара в терминале:
```bash
python test_parser.py
```

### Шаг 2: Получите токен бота
1. Перейдите в Telegram к официальному боту [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`, укажите имя и username для вашего бота.
3. Скопируйте полученный API токен.

### Шаг 3: Настройте .env
Откройте файл `.env` в папке проекта и вставьте ваш токен:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
POLL_INTERVAL=20
DB_NAME=kufar_bot.db
```

### Шаг 4: Запустите бота
```bash
python bot.py
```
После запуска откройте вашего бота в Telegram и отправьте команду `/start`!

## 🎯 Возможности бота

1. **⚡ Готовые пресеты в 1 клик:**
   - 📱 iPhone (до 900 BYN)
   - 🏠 Аренда квартир в Минске (до $350, только от собственников)
   - 🎮 Игровые консоли PlayStation 4 / 5
   - 💻 Ноутбуки MacBook

2. **➕ Пошаговый мастер создания любого фильтра:**
   - Ключевые слова (или поиск по всей категории)
   - Выбор категории (недвижимость, телефоны, авто, ПК и т.д.)
   - Выбор региона (г. Минск или любая область РБ)
   - Фильтр цены (от / до в BYN)
   - Фильтр «Только частные лица» (отсекает риелторов и перекуп-магазины)

3. **🔔 Формат карточки оповещения:**
   - Фотография в высоком качестве
   - Название и бейдж [Собственник]
   - Цена в BYN и пересчет в USD
   - Локация (город, район, станция метро)
   - Инлайн-кнопка прямого перехода на объявление на Куфаре
