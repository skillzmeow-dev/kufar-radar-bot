# 🤖 Telegram-бот замен и расписания для группы 02-24 (МГКСО)

Бот автоматически парсит PDF-файлы замен с Google Диска колледжа, накладывает их на постоянное расписание группы **02-24 РУБ (224)**, вычисляет кабинеты преподавателей (включая динамическую смену кабинетов у Кузьмича и Царикевича) и отправляет готовое итоговое расписание в чат с закреплением.

---

## 🚀 Возможности
1. **Инлайн-кнопки:**
   * 📅 `Расписание на сегодня`
   * ⏭ `Расписание на завтра` (если замены ещё не выложены, бот сообщает об этом, показывает дату последнего файла на Диске и выводит стандартное расписание на этот день недели).
2. **Умное определение кабинетов:**
   * **Кузьмич Д.В.** (МНиЭПА, ЦиМТ) — автоматически берется его кабинет из нижнего списка PDF на нужный номер урока.
   * **Царикевич М.И.** (Основы теории надежности, Электротехника, МиСИ) — аналогично по номеру урока.
   * **Деловые коммуникации** (Друщиц Н.А.) — отображается в расписании, кабинет подставляется при наличии.
3. **Автоматический мониторинг Google Диска:**
   * Каждые 3 минуты проверяет папку Google Диска.
   * При появлении нового PDF автоматически формирует расписание, отправляет его в чат/беседу и **закрепляет сообщение** (`pin`).

## 🌐 Варианты бесплатного хостинга (24/7)

### Вариант 1. Объединить двух ботов на Render.com (Самый удобный лайфхак)
Если у тебя на бесплатном аккаунте Render уже стоит один бот:
* На бесплатном тарифе Render дается **750 часов в месяц на аккаунт** (хватает ровно на 1 процесс 24/7).
* Чтобы оба бота работали бесплатно 24/7, их запускают **в одном сервисе** через простой скрипт `run_all.py`:
  ```python
  import subprocess
  p1 = subprocess.Popen(["python", "bot1.py"])
  p2 = subprocess.Popen(["python", "kso_bot/bot.py"])
  p1.wait()
  p2.wait()
  ```
  Так оба бота работают одновременно, расходуя часы как один процесс!

### Вариант 2. Koyeb (koyeb.com)
* Дает бесплатный инстанс Nano/Micro.
* Не засыпает, работает 24/7 для Telegram-ботов.
* Деплоится в пару кликов прямо из GitHub-репозитория (Dockerfile уже включен в проект).

### Вариант 3. Railway.app
* Дает стартовые $5 / ежемесячные бесплатные кредиты.
* Очень удобный интерфейс и мгновенный деплой.

### Вариант 4. Домашний роутер (Keenetic, OpenWrt, Asus c USB)
Если у твоего роутера есть USB-разъем для флешки:
1. Установи пакетный менеджер **Entware**:
   ```bash
   opkg update
   opkg install python3 python3-pip
   ```
2. Скопируй файлы бота на флешку роутера:
   ```bash
   pip3 install -r requirements.txt
   ```
3. Запусти в фоновом режиме:
   ```bash
   nohup python3 bot.py > bot.log 2>&1 &
   ```
   Бот будет крутиться дома абсолютно бесплатно, потребляя минимум памяти (~30 МБ).
